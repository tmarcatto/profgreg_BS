# Prof Greg V0 Process Approval Contract

This contract defines how approvals work while Prof Greg is still being built.

During v0 development, approval means the current artifact is good enough to unlock the next pipeline stage. It does not mean the artifact is final-quality for commercial release.

## Purpose

V0 approvals allow the team to build the full end-to-end workflow before optimizing every individual stage.

The intended sequence is:

1. Build the whole pipeline.
2. Run a new test course/material through the full process.
3. Use that run to refine prompts, skills, contracts, design, source discipline, rendering, localization, and QA.

## Meaning of V0 Approval

When the user approves an artifact during v0, treat it as:

- accepted for process continuation;
- approved enough to test the next stage;
- not necessarily final for publication;
- still eligible for later redesign, rewriting, QA tightening, or automation improvements.

## What V0 Approval Does Not Mean

It does not mean:

- the artifact is commercially final;
- the design system is final;
- every workflow edge case is solved;
- all localization rules are complete;
- future test runs should copy every content or design choice exactly.

## Required Record

When a v0 approval is used, the approval note should say:

```text
V0 process approval: approved to continue building and testing the pipeline. Subject to later refinement after full-flow testing with another material.
```

## Future Refinement Pass

After the full pipeline exists, Prof Greg should run a separate refinement pass on a new material.

The refinement pass should evaluate:

- intake friction;
- Course Map quality;
- source research and ledger strength;
- draft quality;
- reviewer usefulness;
- DOCX/PDF rendering;
- visual system;
- deck usefulness;
- localization quality;
- approval gates;
- traceability.

## Operator Behavior

When the user says an approval is for v0, Greg should continue building the process rather than treating the current artifact as the permanent gold standard.
