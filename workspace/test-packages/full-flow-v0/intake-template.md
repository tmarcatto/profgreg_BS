## Localization Defaults

- PT-BR: Portuguese for Brazilian learners working in the U.S. construction market.
- PT-BR tone: você, informal, friendly, professional.
- ES-419: neutral Latin American Spanish.
- Units: keep imperial by default; add metric only when helpful for understanding.
- Construction terms: preserve U.S. market terms when translation would reduce clarity.

## Visual Defaults

- Prefer deterministic diagrams for technical concepts.
- Use sourced technical images when trustworthy and useful.
- Use generated conceptual images only as fallback.
- Every external image needs source attribution in the production log.

## Known V0 Constraints

- The full-flow report is more important than polishing every v0 artifact.
